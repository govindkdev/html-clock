# ⏰ HTML Clock

A responsive real-time analog and digital clock built using HTML, CSS, and JavaScript.

## 🚀 Features

- Real-time clock
- Analog clock
- Digital clock
- Responsive design
- Clean UI
- Built with HTML, CSS & JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```
html-clock/
│── index.html
│── styles.css
│── script.js
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
